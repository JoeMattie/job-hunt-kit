# Review Application

1. Read AGENTS.md. If no application folder exists for the job, or resume.md or cover-letter.md still holds template placeholders, follow create-targeted-resume or write-cover-letter first. Then read the saved posting, profile, application.json, the actual drafts, and on a learned packet the voice skill and profile. Run `uv run -q scripts/hunt.py validate` first; resolve a changed-profile report by rechecking evidence before `refresh-snapshot`.
2. Check every factual assertion against confirmed claims and their original sources. Check that every assertion has an evidence record and that every cited claim actually supports its wording. Verify dates, numbers, degree status, exact titles, team attribution, contact details, and links. Automated linkage checks cannot establish truth or complete coverage.
3. Compare requirement map with the original posting. Report uncovered requirements and inaccessible/stale posting information. Never fix a gap by embellishment.
4. Check the prose. On a learned packet compare it against the approved voice rules and examples. On a neutral packet check it is plain, direct, and follows the candidate's stated preferences; voice_checked then means that check was done. On both: register, forced quirks, fabricated motivation, brochure language, repetition, placeholders, internal citations, and accidental disclosure. Confirm final text contains no review notes.
5. Produce the files the candidate will upload. Export with `uv run -q scripts/hunt.py export` when Pandoc is present; otherwise produce the DOCX (and PDF if asked) from the final Markdown with your own document tools into the same job folder; if your DOCX library is unavailable, convert through HTML with `soffice --headless --convert-to docx` when LibreOffice is installed, and if nothing works deliver the Markdown and say so in one line. Do not call a packet ready without an uploadable file unless the candidate said Markdown is enough. Inspect each page and extracted reading order. Set layout_checked only after actual visual review; successful conversion alone is insufficient. If no tool can render or inspect the file, leave it false and say so.
6. Write an actionable review.md. Set facts_checked and voice_checked only after the corresponding review, then set status to reviewed. Candidate approval is separate: ask for it in one line, and only on an explicit yes set approved_by and status ready. Do not submit. List the concrete remaining actions, or say the packet is ready and name the file to upload.
