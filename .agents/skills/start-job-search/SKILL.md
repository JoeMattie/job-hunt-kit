# Start Job Search

1. Read AGENTS.md. The candidate is not expected to use a terminal; you run every command. Check that `uv` is on PATH. If it is not, explain in one sentence that a small local bookkeeping script needs it, show the official installer command `curl -LsSf https://astral.sh/uv/install.sh | sh`, and ask for permission before running it. Then run `uv run -q scripts/hunt.py status`, which creates the workspace on first run and never overwrites existing data.
2. If the candidate name is empty, ask in one short batch, every item optional: preferred name as it should appear on applications, email and phone for applications, city or region, target roles, any location or remote constraints, whether they have an old resume, CV, or transcripts to share (any format), and whether they have a preference for resume length (default two pages) or cover letter length (default 250 to 350 words). Accept partial answers; record anything missing in open_questions. Save to profile.json and run `uv run -q scripts/hunt.py validate`.
3. Explain the plan in plain words: a career interview builds the master CV, which is the long part and usually takes a few sittings, starting from any old resume; a few writing samples teach your voice, or you can choose plain drafts; then each job gets a resume, a cover letter, and a review. State that the candidate always submits applications themselves and that nothing personal is ever uploaded.
4. If the candidate arrived with a job posting that is not yet saved, write the pasted text to workspace/inbox/COMPANY-ROLE.txt and save it with `uv run -q scripts/hunt.py new-job COMPANY ROLE --url URL --description FILE` and continue in the order create-targeted-resume step 1 gives: career history, then voice. If there is no posting, start with assemble-master-cv unless the candidate would rather begin with writing samples. Do not invent an inventory from this conversation or from the repository.
5. Run `uv run -q scripts/hunt.py status` and show the result in plain words. Tell the candidate they can say "where do things stand" at any time for this view, and "back up my job search" to get a dated zip of their data saved outside the repository.
