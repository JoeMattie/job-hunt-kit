# Source handling
Import only candidate-selected material. Prefer local exports or explicitly selected message IDs, threads, files, or folders; folder selection must state whether it includes descendants. Access does not authorize broader searching. A candidate may ask the agent to read a bounded slice of their own accounts for one project, for example emails and spreadsheets about a move within a date range; the agent then agrees the account, terms, dates, and folders, reports the query and match count before reading, uses only those items, records them in a manifest, and treats third parties in them by role only. Verify which person authored each passage, remove quoted replies, and exclude other people's personal details. When a third party's email or message is kept as project evidence, store a redacted copy in workspace/sources, not the original. Keep a manifest of what was selected, what was excluded, and why. No analytics, telemetry, automatic account scraping, or model API calls are built into this toolkit. The coding agent itself is a hosted service: everything the candidate pastes, attaches, or lets the agent read in this folder is sent to that agent's provider (Anthropic for Claude Code, OpenAI for Codex) and handled under that provider's terms. So give the agent only the candidate's own writing and career facts, never a shared inbox, other people's messages, or anything containing passwords, account numbers, or health details.

All personal data lives under ignored workspace/, including voice, CV, source extracts, and application packets. The repository itself is public and must stay free of candidate data; the ignore rules are the only barrier, so never bypass them. Back up workspace separately with `uv run -q scripts/hunt.py backup`, which zips it to `~/Documents/job-hunt-kit-backups` or a folder the candidate names; ignored files are never on GitHub, so that zip is the only copy outside this folder. Documents often syncs to iCloud on a Mac, so say so when reporting where the zip landed and offer a non-synced folder if the candidate prefers. To restore, unzip the backup so that `workspace/` sits at the top of a fresh copy of this folder; the agent does this when asked. Before any commit run `git diff --cached --name-only` and verify no personal material was staged. Never force-add ignored content. If credentials are exposed, revoke them; deleting a file does not erase Git history.
