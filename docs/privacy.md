# Source handling
Import only candidate-selected material. Prefer local exports or explicitly selected message IDs, threads, files, or folders; folder selection must state whether it includes descendants. Access does not authorize broader searching. Verify which person authored each passage, remove quoted replies, and exclude other people's personal details. Keep a manifest of what was selected, what was excluded, and why. No analytics, telemetry, automatic account scraping, or model API calls are built into this toolkit. An agent's own processing environment still applies.

All personal data lives under ignored workspace/, including voice, CV, source extracts, and application packets. A private remote controls access but is not end-to-end encryption. Back up workspace separately; ignored files are absent from Git bundles. Before any commit run `git diff --cached --name-only` and verify no personal material was staged. Never force-add ignored content. If credentials are exposed, revoke them; deleting a file does not erase Git history.
