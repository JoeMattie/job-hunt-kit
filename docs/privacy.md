# Source handling
Import only candidate-selected material. Prefer local exports or explicitly selected message IDs, threads, files, or folders; folder selection must state whether it includes descendants. Access does not authorize broader searching. Verify which person authored each passage, remove quoted replies, and exclude other people's personal details. Keep a manifest of what was selected, what was excluded, and why. No analytics, telemetry, automatic account scraping, or model API calls are built into this toolkit. The coding agent itself is a hosted service: everything the candidate pastes, attaches, or lets the agent read in this folder is sent to that agent's provider (Anthropic for Claude Code, OpenAI for Codex) and handled under that provider's terms. So give the agent only the candidate's own writing and career facts, never a shared inbox, other people's messages, or anything containing passwords, account numbers, or health details.

All personal data lives under ignored workspace/, including voice, CV, source extracts, and application packets. A private remote controls access but is not end-to-end encryption. Back up workspace separately with `python3 scripts/hunt.py backup`, which zips it to a private folder; ignored files are absent from Git bundles and from the remote. Before any commit run `git diff --cached --name-only` and verify no personal material was staged. Never force-add ignored content. If credentials are exposed, revoke them; deleting a file does not erase Git history.
